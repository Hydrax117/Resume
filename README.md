# Portfolio Website

An interactive portfolio website with a unique gate entrance animation and Windows 11-inspired desktop interface.

## Features

- 🚪 Animated gate entrance
- 🖥️ Windows 11-style desktop interface
- 📁 Draggable windows for different sections
- 🎯 Taskbar with start menu
- ⏰ Live clock
- 📱 Responsive design

## Sections

- **About Me** - Personal information and introduction
- **Projects** - Showcase of your work
- **Skills** - Technical skills and expertise
- **Contact** - Contact form

## Customization

Edit the content in `script.js` under the `appContent` object to personalize:
- Your information
- Projects
- Skills
- Contact details

## Usage

Simply open `index.html` in a web browser. No build process required!

## Technologies

- HTML5
- CSS3 (with animations and backdrop-filter)
- Vanilla JavaScript
